## 两个视图

| hash | 视图 |
|---|---|
| `#/` | 提案列表：新建表单 + 历史/进行中的提案 |
| `#/p/<提案 id>` | 提案详情 · 讨论 |
| `#/p/<提案 id>/doc` | 提案详情 · 设计文档 |

设计文档的 Markdown **在服务端**渲染（[`../markdown.py`](../markdown.py)），
前端只负责把 HTML 贴上去 —— 理由见
[docs/web-ui.md](../../docs/web-ui.md) §3.2。

## 硬性约束

- **零构建**：不许用 npm、TypeScript、JSX、任何打包器、任何 CDN 外链
- **零资源文件**：不引入字体与图片，图标用 Unicode 字符
- **不许隐藏事实**：出错、未收敛、某人缺席，都必须显示出来
- **断网可用**：除 LLM 调用外，页面在断网时仍能正常工作
  （这条决定了不能有任何外部资源引用）

## 与后端的关系

由 [`../server.py`](../server.py) 用标准库 `http.server` 提供，
只监听 `127.0.0.1`。接口清单见
[docs/web-ui.md](../../docs/web-ui.md) §8.2。

前端**不认识 LLM**，只消费 SSE 事件流 —— 这是
[架构分层禁令](../../docs/architecture.md) §2 的规定。
